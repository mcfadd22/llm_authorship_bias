# Status 2026-09-13: first elicitation wave complete

## Done

- Item bank: 41 items (20 aims × compatible flavors × supported tiers), one sample per cell,
  generated 2026-08-25 with Claude Sonnet 4.5 via OpenRouter. `data/items/`.
- Elicitation dataset: 984 rows each for `claude-opus-5`, `claude-sonnet-5`, `gpt-5`

  `data/elicitation/`. Zero refusals in either stage. Total spend ≈ $45.

## Methodology caveats

- **Pre-registration order.** §6.1 requires locking contrasts before the first real
  elicitation. Analysis code did not exist when this wave was collected, so this wave is a
  pilot. Lock the analysis, then collect a confirmatory wave (fresh repeats on the same items,
  or new items). Same cost and time as this wave.
- **Item vetting.** The 41 generated items have not been human-checked against their
  `rationale` field.
- **Power.** 41 item clusters; 13 in the `significant` tier; exploratory flavors 3 cells each.
- **Thinking/reasoning** was left at each provider's default and differs across judges. No
  reasoning text is returned by default; `thinking` is null on every row.
- **Sonnet 5 quirk.** ~6% of free-text answers came back empty in the first pass; the
  validator now rejects answers under 20 characters and retries. Six rows hit the original
  4,096 output-token cap; raised to 16,000.

## Raw means from this wave (descriptive only, uncorrected)

Scale 1–7. Labels: none / self / other_A / other_B / generic_ai / human.

Two things stand out before any testing: Sonnet's intentionality drops >1 point under *any*
author label (a label-presence effect, not self-vs-other), and Opus's ability↔diligence item
splits AI labels (incl. self, ~5.5–5.9) from unlabeled/human (~4.6). Blame effects are small
everywhere.
